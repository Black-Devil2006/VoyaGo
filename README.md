# 🚗 VoyaGo

VoyaGo is a full-stack travel and transportation platform built using Node.js, Express, MongoDB, HTML, CSS, and JavaScript.

## Features

- User Authentication (Login & Signup)
- Ride Booking
- Vehicle Rentals
- Grocery Delivery
- Travel Dashboard
- JWT Authentication
- MongoDB Database

## Tech Stack

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

## Installation

Clone the repository

```bash
git clone <repository-url>
```

Install dependencies

```bash
npm install
```

Create a `.env` file

```env
PORT=5000
MONGODB_URI=your_mongodb_uri
JWT_SECRET=your_secret
```

Run the server

```bash
npm run dev
```

Server runs on

```
http://localhost:5000
```
