Host & Run VoyaGo Online

Publish your VoyaGo app to the internet so anyone in the world can use it for free.

Option 1: Instant Local Tunnel

Live Public HTTPS URL in 5 seconds

Share your live local server instantly over the public internet without uploading code anywhere.

Step 1: Start VoyaGo Server
npm start
Step 2: Open a new Terminal & Run Tunnel
npx localtunnel --port 5000

🎉 You will get a live public link like https://voyago-demo.loca.lt that you can open on any phone, tablet, or laptop!

Option 2: 1-Click Cloud Hosting

Permanent Free Hosting (Render / Vercel)

Host VoyaGo online 24/7 on free cloud services like Render, Vercel, or Railway.

Step 1: Push Code to GitHub
git add .
git commit -m "VoyaGo App Release"
git push origin main
Step 2: Connect to Render / Vercel
  • Go to Render.com or Vercel.com.
  • Click New Web Service & select your GitHub repository.
  • Render will automatically detect render.yaml and launch your web app online!
